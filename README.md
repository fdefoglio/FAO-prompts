# FAO-prompts
Prompt repository for FAO editorial work

## Contents

- `FAO_comment-sheet_finalisation_prompt_TEMPLATE.md`: comment-sheet finalisation prompt.
- `format_references.py`: reference formatting helper.
- `nocs/`: NOCS country-name check (`nocs_check.py`, tests, official NOCS export). See `nocs/README.md`. The FAO skills fetch it from here at run time.
